# Prompt Folding

[![License: BY-NC-ND-LinkOnly](https://img.shields.io/badge/license-BY--NC--ND--LinkOnly-lightgrey)](LICENSE)

这个 SillyTavern 扩展可以把 OpenAI／Chat Completion 的提示词管理器整理成可折叠分组。停用分组标题后，组内提示词会从提示词列表中排除。

> [!NOTE]
> 扩展界面使用繁体中文；下面的按钮名称与界面一致。

## 功能

- 手动选择标题，或使用自定义标记按名称分组。
- 单独展开、折叠分组，也可以一次展开、折叠全部分组。
- 在 Preset 之间复制折叠设置，并随 Preset 一起导出。

## 折叠模式

### 手动选择
在 **分組設定**（⚙️）中选择 **手動選擇模式**，点击 **開始選擇資料夾**，勾选要作为标题的提示词，再用绿色勾确认或红色 × 取消。每个标题会收起后续提示词，直到下一个标题为止。

### 标准模式
在 **舊版模式** 中选择 **標準模式**。名称以指定符号开头的提示词会成为标题；默认符号是 `=` 和 `-`。修改 **分組標示符號（一行一個）** 后，点击勾应用。

### 包覆模式
在 **舊版模式** 中选择 **包覆模式**。每个标题会与下一个标题配对，中间的条目和结尾标题都属于该分组；两个标题的名称不必相同。

```text
= 开始
攻击／防御
- 结束
```

## 使用

- 点击分组箭头或标题名称即可展开、折叠；点击标题名称不会打开编辑器。
- 工具栏的 **展開所有**、**收合所有** 控制全部分组。**🟢／🔴** 切换分组和组内过滤功能；**⚙️** 打开设置。
- 停用标题会从提示词列表中排除子项，不会改变子项本身的开关。重建分组时会应用停用样式。
- 在 **從其他 Preset 複製配置** 中选择来源并点击 **複製**。手动标题按 UUID 匹配，无法匹配的标题会被丢弃。
- **折設定** 可以折叠 OpenAI 设置区，其状态独立于 Preset 保存。导出 Preset 会包含折叠设置；导入时如果有设置则会加载。
- **重設所有設定** 会将当前 Preset 的折叠设置恢复为默认值。

> [!WARNING]
> 不建议拖拽提示词来调整顺序。

## 安装

1. 在 SillyTavern 的 **Extensions** 标签页中，使用 `https://github.com/iiimabbie/ST-PromptFolding` 安装。
2. 保持扩展文件夹名为 `ST-PromptFolding`，并启用 **Prompt Folding**。
3. 打开 OpenAI／Chat Completion 提示词管理器，扩展会在此运行。
